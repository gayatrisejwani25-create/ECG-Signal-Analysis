# ECG Signal Analysis

## Signals and Systems Project

This project demonstrates the analysis of an ECG signal using Signals and Systems concepts.

### Features

- ECG signal visualization
- Continuous-time to discrete-time sampling
- Sampling frequency and sampling interval
- Digital ECG representation: x[n] = x(nT)
- Digital band-pass filtering
- R-peak detection
- Heart-rate estimation

### Technologies Used

- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib
- SciPy

### Project Flow

Heart → ECG Sensor → Continuous ECG Signal → Sampling → Digital ECG → Filtering → R-Peak Detection → Heart Rate

### Files

- `app.py` — Streamlit application
- `ecg_sample.csv` — ECG sample data
- `requirements.txt` — Python dependencies

### Disclaimer

This project is for educational purposes and is not intended for medical diagnosis.
